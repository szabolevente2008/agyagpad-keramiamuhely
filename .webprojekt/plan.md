# Weboldal-generálási terv

## Brand brief összefoglaló
Agyagpad: Fehér Dóra szentendrei kerámiaműhelye. Kézzel készített használati kerámia és kis csoportos (max. 6 fő) korongozó tanfolyamok kezdőknek: kóstoló, négyhetes kezdő kurzus, csapatépítő. Fő cél: jelentkezés tanfolyamra ("Jelentkezem"), másodlagos: ajándékutalvány ("Utalványt adnék"). Megkülönböztető: kis csoport, mindig Dóra tanít, az árban minden benne van.

## Koncepció irányok
1. **A mázpróba**: szeladon, okker, kobalt kőagyag háttéren; Bricolage Grotesque + Literata; mázpróba-lapok mint motívum, tipografikus hero.
2. **Udvari műhely**: dió, moha, mustár len háttéren; Alegreya + Work Sans + Caveat; fotós, magazinszerű, kézírásos jegyzetek, rajzolt térkép.
3. **Forog a korong**: oxidvörös, mélybarna, szilvakék rózsás agyag háttéren; Unbounded + Figtree; forgó korong mint motívum, plakátszerű.

## Mi készül el
- Statikus HTML projekt Tailwind CSS-sel (Play CDN, csak a prototípusokhoz)
- 3 kezdőoldal-prototípus, önálló HTML fájlokként (Codex CLI építi)
- Git repó commitokkal
